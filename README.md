# Abel Mugo - Personal Portfolio (Home Page)

Assignment 1 for **CSN 1101: Web Technologies and Internet Applications**, KCA University.

A responsive, single-page personal portfolio home page built with semantic HTML5 and an external CSS stylesheet. It includes a hero section, an About Me section, a navigation bar and a contact footer.

## Live Deployments

- **GitHub Pages:** https://mugoabel.github.io/my-portfolio/


## Project Structure

```
.
├── index.html        # Home page (header, nav, main, footer)
├── styles.css        # All styling, mobile-first with media queries
├── images/
│   └── abel-mugo.jpg # Compressed headshot
└── README.md
```

## Features

- Semantic HTML5: `<header>`, `<nav>`, `<main>`, `<footer>`
- Fully responsive from 320px to desktop
- Consistent color palette and fonts (Poppins and Inter)
- Compressed profile photo for fast loading

## Run Locally

Open `index.html` in any browser. No build step is needed.
